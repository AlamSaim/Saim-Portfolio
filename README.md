# 🌐 Developer Portfolio Website

A responsive and professional portfolio website built using **React**, **SCSS**, **EmailJS**, **React Hook Form**, and **React Toastify**. It showcases personal projects, skills, resume, and contact functionality with a modern UI.

---

## 🔗 Live Demo

👉 [Click Here to View Live]
https://saim-portfolio-nu.vercel.app/

---

## ⚙️ Tech Stack

- ⚛️ React 18
- 🎨 SCSS (SASS)
- 📧 EmailJS
- 📋 React Hook Form
- 🔔 React Toastify
- 🔤 React Icons
- 🧪 Testing Library (basic setup)

---

## ✨ Features

👋 Hero section with name, intro, and social links

💼 Projects section with GitHub + Live Demo links

🧰 Skills / Tech stack listing

📧 Contact form (using React Hook Form + EmailJS)

🔔 Toast notification on message submission

🎨 Styled with SASS/SCSS for modular CSS

📱 Fully responsive across all devices

🧪 Basic unit test setup with Testing Library
